Учебный мини-тест для самопроверки (не тест преподавателя)
1. Где выполняется fs.readdir и почему? В главном процессе: renderer получает только ограниченный API.
2. Что возвращает ipcRenderer.invoke? Promise с результатом обработчика ipcMain.handle.
3. Как меню обновляет список? main отправляет refresh-request, preload вызывает callback, renderer запускает общую refreshDirectory.
4. Почему EXE на C с /MD меньше варианта /MT? В первом случае библиотека C подключается динамически, во втором включается в файл статически.
5. Зачем в macOS обрабатывать activate? Для создания окна при активации работающего приложения без открытых окон.
