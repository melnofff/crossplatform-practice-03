# Практика 3 — Electron

Мельников Данила Вячеславович, ТРПО23-2. Вариант 4.
Дисциплина: кросс-платформенная разработка.

Файловый просмотрщик с пунктом главного меню «Файл → Обновить список».

## Запуск

Node.js 24 LTS и npm 11. Установить зависимости: `npm ci`.
Для Electron 44 отдельно загрузить runtime: `npx install-electron`.
Запустить: `npm start`. Нажать «Показать содержимое каталога».
Обновить список через меню «Файл» или Ctrl+R (Cmd+R на macOS).
Программа показывает рабочую папку процесса — каталог, из которого запущено приложение.
Для установленной программы папка зависит от ярлыка/способа запуска и показана в окне.

## Сборка и проверки

`npm test` — проверки чтения каталогов.
`npm run dist` — сборка NSIS для Windows x64; результат в dist/.
Установщик учебный, без цифровой подписи. macOS/Linux на этом компьютере не проверены.
main.js отвечает за окно, IPC и меню; directory.js читает каталог;
preload.js предоставляет узкий API; renderer.js обновляет DOM через textContent.
contextIsolation=true, nodeIntegration=false, sandbox=true.
Меню и кнопка вызывают одну функцию обновления. Произвольные пути через IPC запрещены.
